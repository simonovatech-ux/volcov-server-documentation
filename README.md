# Документация сервера Volcov AI

Этот репозиторий описывает сервер приложений `159.194.228.119`: размещённые контуры, Docker-архитектуру, проверки состояния, резервное копирование, обслуживание и безопасную очистку.

Инвентаризация выполнена 10 сентября 2026 года в режиме только чтения. Содержимое `.env`, ключей, токенов и баз данных не читалось и в документацию не включено.

| Контур | Состояние | Назначение |
|---|---|---|
| `demo-flow-mcp` | Работает | Основной MCP, фоновые процессы, транскрибация и HTTPS-прокси |

| `bitrix-plan-autofill` | Работает | Автозаполнение планов в Битрикс24 |
| `novinki` | Работает | MAX-помощник продавца и PostgreSQL |

| `sber-max-bot` | Остановлен | Пилот решений руководителя в MAX |

Основные показатели сервера:

- Ubuntu 24.04 LTS, виртуальная машина KVM;
- 4 ГБ оперативной памяти, swap отсутствует;
- системный диск 40 ГБ, после безопасной очистки занято около 39%;
- 14 Docker-контейнеров: 11 работающих и 3 остановленных;
- наружу опубликованы только TCP-порты `22`, `80` и `443`;
- активных упавших systemd-служб нет.

## Критические действия

1. Сменить пароль `root`, который был опубликован в сообщении со скриншотом.
2. Восстановить `hiring-app` и проверить причину завершения с кодом `137`.
3. Исправить права `/opt/sber-max-bot/.env` с `0644` на `0600`.
4. Установить обновления и выполнить контролируемую перезагрузку сервера.
5. После проверки SSH-ключей запретить вход `root` по паролю.

Документация намеренно не содержит секретов. Значения переменных окружения должны храниться только на сервере или в отдельном менеджере секретов.
